Token Saver

Local proxy for Cursor and Claude Code. Strips bulky context before it hits the model APIs — fewer tokens, same workflow.

Dashboardhttp://127.0.0.1:8081/
Optional URLhttp://tokensaver.local/

Ops boardhttp://127.0.0.1:8081/v2

Quick start

macOS

  1. Double-click start-mac.command — installs deps and starts the proxy.
  2. Double-click Install to Applications.app (or install-to-applications.command).
  3. Open Token Saver → complete the setup wizard (optional: Don’t show this again).
  4. Dock click focuses the existing dashboard tab (or opens a new one). Quit stops the proxy.

Windows

  1. Double-click start-windows.bat — installs deps and starts the proxy.
  2. Open http://127.0.0.1:8081/ — same setup wizard as macOS.
  3. Prefer reverse mode for Claude Code and Cursor OpenAI BYOK (no CA install).
  4. Use .venv\Scripts\python.exe for all commands — not a global Python.
Always run aiproxy with the project venv Python: .venv/bin/python (macOS) or .venv\Scripts\python.exe (Windows).

3. Connect Cursor

MITM — macOS

.venv/bin/python -m aiproxy --mode mitm --dry-run

sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain \
  ~/.mitmproxy/mitmproxy-ca-cert.pem

Cursor settings.json:

{
  "http.proxy": "http://127.0.0.1:8080",
  "http.proxySupport": "override",
  "http.proxyStrictSSL": false,
  "cursor.general.disableHttp2": true
}
export NODE_EXTRA_CA_CERTS="$HOME/.mitmproxy/mitmproxy-ca-cert.pem"
open -a Cursor   # after Cmd+Q quit

OpenAI BYOK — Mac or Windows (recommended on Windows)

.venv/bin/python -m aiproxy --mode openai --dry-run
# Cursor → Settings → Models → OpenAI Base URL:
# http://127.0.0.1:8080/v1
# No CA. Leave http.proxy unset.

Windows MITM (optional)

  1. Start with --mode mitm; trust %USERPROFILE%\.mitmproxy\mitmproxy-ca-cert.cer in Trusted Root.
  2. Same Cursor http.proxy settings as above.
  3. Relaunch Cursor with NODE_EXTRA_CA_CERTS set to the .pem path.

4. Connect Claude Code

# Terminal 1
.venv/bin/python -m aiproxy --mode anthropic --dry-run

# Terminal 2 (macOS / Linux)
export ANTHROPIC_BASE_URL="http://127.0.0.1:8080"
claude

# Terminal 2 (Windows PowerShell)
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:8080"
claude

Persist in ~/.claude/settings.json (Windows: %USERPROFILE%\.claude\settings.json):

{
  "env": { "ANTHROPIC_BASE_URL": "http://127.0.0.1:8080" }
}

Not covered: claude.ai in the browser, Claude Desktop.
